Pyro is a blazing‑fast 🔥 terminal toolkit that supercharges Python development from one sleek CLI.  
It manages packages, virtual envs, projects, builds, EXE bundles, and AI‑powered workflows in seconds—no more juggling dozens of tools. 🚀

> One EXE. One window. Turn your machine into a Python forge. ⚡

---

## ✨ Features

- 🔥 **Package smith** – install, upgrade, remove and search PyPI packages with nice output.  
- 🧪 **Virtual env alchemist** – create, clone, activate, and inspect virtual environments in a few key presses.  
- 🧱 **Project foundry** – scaffold CLI, Flask, FastAPI, ML or library projects with ready‑to‑run layouts.  
- 🧬 **Library builder** – build wheels, install locally, and prep releases without touching `setup.cfg` by hand.  
- ⚙️ **EXE forge** – wrap Python apps into Windows executables with a guided PyInstaller flow.  
- 📊 **Stats view** – see environment health, package counts, disk usage, and ecosystem metrics in TUI charts.  
- 🤖 **AI lane** – stream chat with local LMs (LM Studio, Ollama, etc.) directly from the terminal while you code.  
- 🩺 **Doctor** – quick diagnostics for PATH, Python versions, pip issues, and broken venvs.  
- 🛠️ **System setup** – first‑run helpers to get a clean Python toolchain on a fresh Windows install.

## 🚀 Getting Started

### 1. Download

1. Grab the latest `Pyro.exe` from the **Releases** page.  
2. Put it somewhere on your disk (for example: `C:\Tools\Pyro`).

### 2. Add to PATH (recommended)

1. Open the Windows start menu and search for **Environment Variables**.  
2. Edit the `PATH` for your user and add the folder where `Pyro.exe` lives.  
3. Restart your terminal.

Now you can run:

```bash
pyro
